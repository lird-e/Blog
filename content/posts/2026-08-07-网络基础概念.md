## 一、网络基础概念

### 1.1 IP 地址

IP 地址是设备在网络中的唯一标识，分为 IPv4（32 位，如 `192.168.1.100`）和 IPv6（128 位）。

- **公网 IP**：互联网上可直接路由的地址，由运营商分配
- **内网 IP（私有地址）**：局域网内使用，不可在互联网上路由
  - `10.0.0.0 ~ 10.255.255.255`（A 类）
  - `172.16.0.0 ~ 172.31.255.255`（B 类）
  - `192.168.0.0 ~ 192.168.255.255`（C 类，家用最常见）

### 1.2 子网掩码

> 个人笔记：子网掩码是用来告诉设备，一个 IP 地址哪些部分是网络位、哪些是主机位，主要作用就是区分网段，查看两台设备是否在同一网段。

子网掩码是一个 32 位二进制数，掩码中 `1` 对应网络号，`0` 对应主机号。

- 家用默认 `255.255.255.0`（即 /24），同一网段最多 254 台设备
- 两台设备网络号相同 → 可直接通信，不需经过路由器
- 网络号不同 → 必须通过路由器转发

**计算示例**：
```
IP:      192.168.1.100
掩码:    255.255.255.0
网络号:  192.168.1.0
主机号:  100
```

### 1.3 网关（Gateway）

> 个人笔记：局域网内通常可以不配置网关，因为大家都知道 IP，直接相互访问就行；如果要访问外网，设备不知道要去哪，通常就直接发给网关，由网关进行下一步操作。

网关是本网段通往其他网络的"出口"，通常就是路由器的内网 IP（如 `192.168.1.1`）。

- 设备访问外网时，数据包先发给网关，再由网关转发
- 网关配置错误 → 能 ping 通同网段设备，但上不了网

### 1.4 DNS（域名系统）

DNS 负责把域名（如 `www.baidu.com`）翻译成 IP 地址。

- DNS 配置错误 → 能 ping 通 IP 但打不开网页（"能上 QQ 不能开网页"的典型原因）
- 常用公共 DNS：`114.114.114.114`、`8.8.8.8`、`223.5.5.5`（阿里）

### 1.5 MAC 地址

MAC 地址是网卡的物理地址，全球唯一，48 位，如 `00:1A:2B:3C:4D:5E`。

- 工作在数据链路层，用于同一网段内的设备通信
- ARP 协议负责把 IP 地址解析为 MAC 地址
- MAC 地址可被克隆/修改，部分运营商绑定 MAC 认证

### 1.6 NAT（网络地址转换）

NAT 让内网多台设备共享一个公网 IP 上网，是家用路由器的核心功能。

- 出站：内网访问外网时，路由器替换源 IP 和端口
- 端口映射/虚拟服务器：让外网能访问内网指定设备（如摄像头、NAS）

## 二、家用路由器

### 2.1 路由器的作用

> 个人笔记：家用路由器通常是家庭网络的网关，接入外部网络，并分发给下级各类设备。

家用路由器集成了**路由 + 无线 AP + 交换机**三大功能：

1. 拨号连接运营商宽带（PPPoE / DHCP）
2. 通过 NAT 让多设备共享上网
3. 提供 Wi-Fi 无线网络
4. 提供有线 LAN 口连接
5. DHCP 自动分配 IP
6. 基础防火墙防护

### 2.2 关键参数

| 参数 | 说明 | 建议 |
|------|------|------|
| Wi-Fi 标准 | Wi-Fi 5(ac) / Wi-Fi 6(ax) / Wi-Fi 7 | 优先 Wi-Fi 6 及以上 |
| 频段 | 2.4G（穿墙好、慢）/ 5G（快、穿墙弱）/ 6G | 双频起步，大户型三频 |
| 网口速率 | 百兆 / 千兆 / 2.5G | 宽带 ≥100M 必须全千兆 |
| 带机量 | 同时连接设备数 | 由 CPU 和内存决定 |
| Mesh | 多台组网无缝漫游 | 大户型/复式推荐 |

### 2.3 光猫与路由器

- **光猫**：运营商提供，负责光电转换，部分自带 Wi-Fi（性能弱）
- **推荐方案**：光猫改**桥接模式**，由路由器拨号，性能和稳定性更好
- 光猫自带 Wi-Fi 仅适合极小户型、设备少的场景

### 2.4 摆放与优化

- 放在家中**开阔、居中、较高**的位置
- 远离微波炉、蓝牙设备、金属遮挡、弱电箱
- 天线错开不同角度，不要全朝一个方向
- 大户型使用 Mesh 组网，优先有线回程

## 三、Wi-Fi 知识

### 3.1 频段对比

| 频段 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| 2.4GHz | 穿墙好、覆盖远 | 速度慢、干扰多（蓝牙、微波炉、邻居） | 远距离、IoT 设备 |
| 5GHz | 速度快、干扰少 | 穿墙弱、覆盖近 | 近距离、高清视频、游戏 |
| 6GHz（Wi-Fi 6E/7） | 极快、几乎无干扰 | 穿墙最弱、设备少 | 旗舰设备、高密度场景 |

### 3.2 信道选择

- 2.4G 推荐使用 **1、6、11** 三个互不重叠的信道
- 5G 信道多、干扰少，一般自动即可
- 可用 Wi-Fi 分析仪（手机 APP）查看周围信道占用，选择最空的信道

### 3.3 常见 Wi-Fi 标准

| 标准 | 频段 | 理论最大速率 |
|------|------|------------|
| 802.11n（Wi-Fi 4） | 2.4G/5G | 600 Mbps |
| 802.11ac（Wi-Fi 5） | 5G | 3.5 Gbps |
| 802.11ax（Wi-Fi 6） | 2.4G/5G | 9.6 Gbps |
| 802.11be（Wi-Fi 7） | 2.4G/5G/6G | 46 Gbps |

## 四、网络协议与端口

### 4.1 常用协议端口

| 协议 | 端口 | 用途 |
|------|------|------|
| HTTP | 80 | 网页浏览 |
| HTTPS | 443 | 加密网页浏览 |
| FTP | 20/21 | 文件传输 |
| SSH | 22 | 远程登录 |
| Telnet | 23 | 远程登录（明文，不推荐） |
| DNS | 53 | 域名解析 |
| DHCP | 67/68 | 自动分配 IP |
| SMTP | 25 | 发送邮件 |
| POP3 | 110 | 接收邮件 |
| RDP | 3389 | Windows 远程桌面 |
| MySQL | 3306 | 数据库 |
| Redis | 6379 | 缓存数据库 |

### 4.2 TCP 与 UDP

- **TCP**：面向连接，可靠传输，有三次握手和四次挥手，适合网页、文件传输
- **UDP**：无连接，不可靠但速度快，适合视频直播、游戏、语音通话

## 五、网络排障

### 5.1 分层排查法（OSI 七层模型）

从下往上逐层排查，定位问题层级：

| 层级 | 排查内容 | 方法 |
|------|---------|------|
| 物理层 | 网线、端口、电源、指示灯 | 看灯、换线、换口 |
| 数据链路层 | MAC 地址、VLAN、ARP | `arp -a`、检查 MAC 绑定 |
| 网络层 | IP、掩码、网关、路由 | `ipconfig`、`ping 网关` |
| 传输层 | 端口、TCP/UDP | `telnet`、`netstat` |
| 应用层 | DNS、HTTP、服务配置 | `nslookup`、浏览器测试 |

### 5.2 常用排障命令

#### Windows

```powershell
# 查看网络配置
ipconfig /all

# 释放并重新获取 IP
ipconfig /release
ipconfig /renew

# 刷新 DNS 缓存
ipconfig /flushdns

# 测试连通性
ping 192.168.1.1
ping www.baidu.com
ping -t 192.168.1.1    # 持续 ping

# 路由追踪
tracert www.baidu.com

# 查看 ARP 表
arp -a

# 查看端口监听
netstat -ano
netstat -ano | findstr :8080

# 测试端口连通性
telnet 192.168.1.100 80
# 或（PowerShell）
Test-NetConnection 192.168.1.100 -Port 80
```

#### Linux / Mac

```bash
# 查看网络配置
ifconfig
ip addr

# 测试连通性
ping 192.168.1.1
ping -c 4 www.baidu.com    # 发 4 个包后停止

# 路由追踪
traceroute www.baidu.com

# 查看端口监听
netstat -tlnp
ss -tlnp

# 测试端口
nc -zv 192.168.1.100 80

# 查看 DNS 解析
nslookup www.baidu.com
dig www.baidu.com

# 查看路由表
route -n
ip route
```

### 5.3 典型故障排查流程

**完全上不了网**

1. 看路由器/光猫指示灯是否正常
2. 手机/电脑是否能连上 Wi-Fi 或获取到 IP
3. `ping 127.0.0.1` → 本机网卡是否正常
4. `ping 网关`（如 192.168.1.1）→ 到路由器是否通
5. `ping 公网 IP`（如 8.8.8.8）→ 到互联网是否通
6. `ping 域名`（如 www.baidu.com）→ DNS 是否正常
7. 哪一步不通，问题就在哪一层

**能上 QQ/微信但打不开网页**

→ 几乎一定是 DNS 问题，检查 DNS 配置或更换公共 DNS

**网速慢**

1. 有线直连光猫测速 → 排除宽带本身问题
2. 有线连路由器测速 → 排除路由器性能瓶颈
3. 无线测速 → 检查信号强度、干扰、频段
4. 检查是否有设备占满带宽（下载、视频）

**频繁断流**

1. 检查路由器温度（过热导致死机）
2. 检查是否有 IP 地址冲突
3. 更新路由器固件
4. 减少同时连接的设备数
5. 更换信道，避免邻居干扰

**部分网站打不开**

1. `nslookup` 检查 DNS 解析
2. `tracert` 看路由在哪一跳断
3. 可能是网站本身问题或运营商线路问题
4. 尝试更换 DNS 或使用代理测试

## 六、实用知识

### 6.1 特殊 IP 段

- `127.0.0.1` → 本机回环地址
- `0.0.0.0` → 所有网卡/任意地址
- `255.255.255.255` → 广播地址
- `169.254.x.x` → DHCP 失败时自动分配的地址（说明没获取到 IP）

### 6.2 端口映射（虚拟服务器）

需要外网访问内网设备时使用：

1. 登录路由器管理页
2. 找到"虚拟服务器"或"端口映射"
3. 外部端口 + 内网 IP + 内部端口 + 协议（TCP/UDP）
4. 注意安全风险，不要随意暴露敏感端口（如 3389、22）

> IPv6 端口转发的具体配置方法见 IPv6 端口转发。

### 6.3 DHCP 与静态 IP

- **DHCP**：自动分配 IP，适合普通设备
- **静态 IP**：手动设置固定 IP，适合服务器、NAS、打印机、摄像头
- 也可在路由器中设置"静态地址分配"，通过 MAC 绑定固定 IP，更方便管理

### 6.4 网速单位换算

- 运营商说的 **100M 宽带** = 100 Mbps（兆比特每秒）
- 实际下载速度 ≈ 100 ÷ 8 = **12.5 MB/s**（兆字节每秒）
- 1 Byte = 8 bit，注意大小写：`Mbps`（比特）vs `MB/s`（字节）
