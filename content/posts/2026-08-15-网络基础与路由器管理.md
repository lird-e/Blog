> 路由器的联网、管理、客户端与无线配置基础，以及 SSH 常用命令。适用于售前配置指导与售后基础排障。

## 一、WAN 与 LAN

| 接口 | 角色 | 说明 |
|------|------|------|
| WAN 口 | 外网接口 | 连接上级网线，向上级获取 IP；一般不向下级下发 IP |
| LAN 口 | 内网接口 | LAN 口之间相互直通；在 LAN 口开启 DHCP 服务，主动下发 IP 给设备 |

- 设备直接连接 WAN 口时**无法获取 IP 地址**
- 出厂默认：LAN IP `192.168.8.1`，掩码 `255.255.255.0`（/24），DHCP 范围 `192.168.8.100 ~ 192.168.8.249`

## 二、两种管理方式：web 页面 vs SSH

| 维度 | web 管理页面 | SSH 后台 |
|------|-------------|----------|
| 访问方式 | 浏览器输入网关 IP，默认内网使用，门槛低 | 终端执行命令，网络要求低，安全性更高 |
| 界面 | 图形化、可视化 | 纯文字、命令操作 |
| 功能 | 日常使用全覆盖，不涉及底层系统 | 权限高，适合高级需求 |

SSH 登录要点：
- Windows 用自带 cmd/PowerShell 或 Putty
- 账号 `root`；输入密码时无显示，输完回车即可

## 三、联网状态判断

| 状态 | 含义 |
|------|------|
| 蓝色缓慢闪烁 | 启动中 / 未联网 |
| 白色常亮 | 已连接上级网络、成功获取 IP |

> 部分型号（如 GL-BE3600）无 LED、带触摸屏，可点击屏幕查看设备状态。

恢复出厂设置：按住 Reset 键约 10 秒，等待重启。

## 四、局域网配置

### LAN IP 冲突

**现象**：下级路由器（WAN 接上级 LAN）无法联网，管理页提示 "IP conflict"。

**处理**：把下级路由器的 Router IP 改为**不同网段**的 IP。

> 下级路由 WAN 有线接入上级时，固件默认保留上级局域网回程路由、不做内网隔离，所以下级网络的终端仍可访问上级路由器管理页面。

### DHCP Server

- 作用：配置 DHCP 地址池，按池范围自动分配 IP
- **禁用后果**：下级设备无法自动获取 IP，需手动配置静态 IP

### 静态 IP 配置要点

- IP 必须在上级网段范围内且**无冲突**（未被占用）
- Netmask / Gateway / DNS 与 DHCP 获取时一致
- 静态配置不依赖 DHCP 服务

### Tethering（USB 共享手机网络）

1. 手机数据线 USB-A 插路由器、USB-C 插手机
2. 手机开启「USB 网络共享」
3. 路由器 web 页面 → INTERNET → Connect，等待连接成功

## 五、客户端管理（CLIENTS 页面）

- 设备列表：IP、MAC、网络速率等信息
- 常用操作：Block（拉黑）、Reserved IP（保留地址）、改名、限速、黑白名单

**限速提示**：CLIENTS 页 Actions 无 Limit Speed 选项时，检查 Speed 栏是否有黄色警示；有则到 NETWORK → Network Acceleration **关闭网络加速**后再限速。
测速工具：speedtest.cn；手机 APP：WiFi 魔盒 / WiFi analyzer / WiFiman / 全球网测。

**黑白名单**：黑名单 = 禁止清单（加入则禁止上网）；白名单 = 允许清单（仅白名单可上网）。

## 六、无线配置（WIRELESS 页面）

两个频段：5GHz 与 2.4GHz。主要参数：SSID、WiFi Security（加密）、WiFi Password、TX Power（发射功率）、WiFi Mode（协议）、Bandwidth（频宽）。

- 修改 SSID/密码后：已连接设备会断开并要求重新认证（手机提示密码错误、电脑提示超时重试）
- 加密选项：不加密 / WPA2-PSK / WPA/WPA2-PSK / WPA3-SAE / WPA2-PSK/WPA3-SAE
- 频段选择：2.4G 穿墙好但慢、干扰多；5G 快但穿墙弱

### Guest WiFi（访客网络）隔离

- 访客可正常上网，但**无法访问路由器管理页面**
- 原因：Guest 与主网络处于**不同网段**（如主网 192.168.8.x / Guest 192.168.9.x），相互隔离
- 验证：主 WiFi 设备 ping 不通 Guest 设备 → 隔离生效

## 七、SSH 常用命令

### ifconfig（有线/网桥接口）

| 接口 | 说明 |
|------|------|
| br-guest | 访客网络网桥，对应访客 WiFi 网段 |
| br-lan | 主局域网网桥，主 WiFi + LAN 口组成内网；`192.168.8.1` 为管理地址 |
| eth0 | 物理以太网接口 = **WAN 口**（获取上级 IP，连接外网） |
| eth1 | 物理以太网接口 = **LAN 口**，桥接到 br-lan，无独立 IP |

| 字段 | 含义 |
|------|------|
| HWaddr | 接口 MAC 地址（全球唯一） |
| inet addr | 接口 IPv4 地址 |
| Mask | 子网掩码；255.255.255.0 = /24 |
| RX/TX bytes | 接口收发总数据量 |

### iwinfo（无线接口）

| 接口 | 说明 |
|------|------|
| sta0 / sta1 | 2.4G / 5G 无线客户端接口（Station 模式），用于中继/无线 WAN |
| wlan0 | 无线主接口（Master/AP 模式），路由器自身发射的热点 |

| 字段 | 含义 |
|------|------|
| Mode | Client（连上级 WiFi）/ Master（发射热点） |
| Channel | 当前信道及工作频率 |
| Encryption | 加密方式 |
| Bit Rate | 协商无线速率 |
| Tx-Power | 发射功率（dBm，越大覆盖越强） |

### ping / traceroute

```text
64 bytes from 8.8.8.8: icmp_seq=0 ttl=111 time=21.652 ms
```

- `64 bytes`：ICMP 包大小；`from`：目标正常回应，网络可达
- `seq`：序列号，检测丢包/乱序；`ttl`：每过一跳减 1
- `time`：往返时延 RTT（ms）
- 统计：`36 transmitted, 36 received, 0% packet loss`；`round-trip min/avg/max`

traceroute 用法：看每一跳节点，**第一跳即出口网关**，据此判断流量走哪个接口（详见 多种联网方式 的 Multi-WAN 部分）。

## 八、U-Boot 刷机（Debrick）

1. 官方 Firmware Download Center 下载对应型号 U-Boot 固件（img；部分型号与常规升级固件相同，注意区分）
2. 电脑手动设静态 IP `192.168.1.2`
3. 路由器断电 → 按住 Reset → 插电，持续按住至指示灯变白
4. 浏览器访问 `192.168.1.1`，上传固件 → Update Firmware
5. 完成后电脑改回 DHCP，访问 `192.168.8.1`
