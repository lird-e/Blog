> 路由器的联网接入方式：有线 Ethernet、无线中继 Repeater、蜂窝 Cellular、随身 uFi、Tethering，以及多 WAN 链路聚合。适用于接入类配置与排障。

## 一、联网方式总览

| 方式 | 适用场景 | 关键点 |
|------|---------|--------|
| Ethernet（有线） | 固定场所 | 稳定，优先级默认最高 |
| Repeater（无线中继） | 无线上级、信号扩展 | 半双工，带宽折损 |
| Tethering（USB 共享） | 手机网络临时共享 | 手机需开 USB 网络共享 |
| Cellular（蜂窝） | 无固网环境 | 需 SIM 卡，支持双卡切换 |
| uFi（随身 WiFi） | 跨境/移动场景 | 插 USB 口，内置 SIM 流量 |

## 二、Repeater 无线中继

### 中继选项（INTERNET → Repeater）

| 选项 | 含义 |
|------|------|
| Auto-Enable Login Mode for Public Hotspots | 公共热点自动登录：上级需网页认证时开启，所有设备共享同一认证会话 |
| Enable Camouflage | 设备伪装：克隆当前登录设备的 MAC，访问上级时伪装成该设备 |
| MAC Mode | Factory（原厂）/ Clone（克隆，绕 MAC 绑定）/ Random（随机，防追踪、提升隐私） |
| Lock BSSID | 锁定上级接入点 |
| Allow Switching to Other Saved Networks | 掉线后自动切换已保存的其他热点，多热点冗余，适合随身路由 |
| Band Selection | 选择扫描/连接频段 |

### 中继模式下的无线参数限制

- **可改**：SSID、密码、Security、SSID Visibility、随机 BSSID、TX Power、WiFi Mode
- **不可改**：Bandwidth、Channel —— 为保持链路稳定，**强制与上级一致**

### 中继速度损耗原理

- 中继 = 无线接收上级 + 无线发射本地，**两次无线收发**
- 无线中继是**半双工**，同一时刻只能收或发，带宽直接折损（约减半）
- 直连设备只做一次无线通信，无二次转发开销
- 测速对比时注意环境因素（同名 SSID、人多）会导致结果不准

## 三、蜂窝网络 Cellular

### 关键参数

| 参数 | 含义 |
|------|------|
| Modem Name | 蜂窝模组的型号名称 |
| IMEI | 模组硬件全球唯一标识（国际移动设备识别码） |
| ICCID | SIM/eSIM 卡出厂固化的全球唯一硬件序列号 |
| APN | 蜂窝分组数据网络网关标识，接入运营商移动数据网络的核心配置，对应运营商核心网 PDN 入口地址 |
| Cells mode（v4.7 称 Service） | 网络制式偏好，定义可接入技术类型与优先级 |

### SIM 卡识别与拨号

- 插入 SIM 卡等待 1~2 分钟，检测到后配置蜂窝拨号上网
- **No SIM card 处理**：① 重插卡 ② 重启路由器 ③ 关机插卡 1 分钟后再开机

### 双卡自动切换（Auto Switch）

| 设置项 | 含义 |
|--------|------|
| Auto Switch | 双卡自动故障切换总开关 |
| Preferred SIM Card Slot | 首选卡槽 |
| Failover Interval | 故障回切检测间隔 |
| Checking Preferred Slot Status Scheduled | 定时检测首选卡槽状态 |

### SMS 与短信转发

- **SMS**：路由器直接收发短信：SIM 状态核验、短信远程运维、验证码代收
- **SMS Forwarding**：自动转发短信至手机/邮箱：野外无人值守告警、双卡短信集中管理、副卡托管

### 锁信号塔（Lock Tower）

**场景**：多基站交叉覆盖区稳定低延迟、高负载基站下优化网速、固定点位长期部署、省界/国界防漫游扣费。

**锁塔断网排查**（按序）：
1. 检查 SIM 卡安装与资费，重启设备
2. 核对目标基站运营商归属与频段，修正频段掩码与 APN
3. 设备换过位置 → 先解锁恢复自动选网
4. 目标基站不可用 → 重新扫描周边基站，筛选正常基站重新锁定

### 锁运营商（Lock Operator）

**场景**：边界防漫游扣费、物联网/定向流量卡、多运营商重叠区稳定网络、排障排除异网干扰。
**支持型号**：GL-X3000、GL-XE3000、GL-X2000。

## 四、SIMPoYo uFi（随身 WiFi）

### 产品要点

- 应用场景：欧洲多国旅游/商务、跨境自媒体直播、车载全域移动 WiFi
- 免费流量：10G / 30 天 / 英国 + 34 欧洲国家
- 兼容：带 USB 口的 GL.iNet 全系列（BE3600、MT3000、SFT1200、MT6000、AX1800 等）
- 后盖信息：SSID、WiFi Key、Admin PW；默认密码登录会提示更改

### 安装与连接

1. SIM 卡装入 uFi，插路由器 USB 口，等 1~2 分钟
2. LED 变化：白常亮 → 红闪 → 蓝常亮（上电）；蓝 → 绿（连接成功）
3. 路由器 web → INTERNET → Tethering → Connect，路由器通过 uFi 的 SIM 卡联网
4. 可连接 uFi 自身 WiFi，进入其管理页（后盖 IP + 默认密码）

> 供电不足：uFi 插 USB 后 LED 无反应 → 更换电源适配器（9V, 3A）。

### 蜂窝状态参数（uFi Status）

| 参数 | 含义 |
|------|------|
| RSRP | 参考信号接收功率 |
| SINR | 信号与干扰加噪声比 |
| RSRQ | 参考信号接收质量 |
| RSSI | 接收信号强度指示 |
| PCI | 物理小区标识，区分相邻基站/扇区 |
| CELL_ID | 小区 ID，全网唯一标识基站小区 |
| PLMN | 公共陆地移动网络码（国家码+运营商码） |
| EARFCN | 绝对无线频率信道号 |
| ECGI | 演进型小区全局标识符，精准定位基站小区 |
| ULFREQ/DLFREQ、ULBW/DLBW | 上下行频率 / 上下行带宽 |

## 五、Multi-WAN 多链路

### 接口状态跟踪

- 通过 **ICMP（Ping）** 跟踪接口状态：向探测目标发包，根据返回判断连通
- **禁用跟踪**：只判断物理链路（Link up/down），不检测互联网是否可达

### 两种模式

| 模式 | 机制 | 特点 |
|------|------|------|
| Failover（故障转移） | 主备链路，主链路故障自动切换备用 | 同一时刻仅一条链路工作；**默认模式**；最高优先级默认 Ethernet |
| Load Balance（负载均衡） | 多链路同时承载，按权重分配流量 | 带宽叠加 + 故障切换能力 |

**负载比**：各接口流量分配权重，按比例分配**新建连接**；单条连接固定走一条链路。例：有线 WAN 3 : USB 1，按 3:1 分配。

### 验证流量出口（traceroute）

```bash
traceroute www.baidu.com
```

- **第一跳 = 出口网关**，据此判断流量走哪个接口（第一跳看不出看第二跳）
- 例：第一跳 10.100.208.1 → 走 Ethernet；第一跳 10.100.50.1 → 走 Repeater

**Failover 验证**：配置多接入（Ethernet+Repeater+Tethering 等），拔掉 WAN 网线模拟故障，再 traceroute 确认流量自动切换；更改接口优先级后再次验证。
