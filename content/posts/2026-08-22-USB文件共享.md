> 路由器外置存储的文件共享方案：Samba、WebDAV、DLNA 的配置、访问方法与安全注意。

## 一、三种共享方式对比

| 方式 | 协议/特点 | 适用场景 |
|------|----------|---------|
| Samba | 适配内网 Windows 原生文件共享；通用全文件共享，支持读写与精细权限 | 电脑文件操作、内网共享 |
| WebDAV | HTTP/HTTPS 传输、可自定义端口、无独立共享名；跨平台兼容性更好、外网穿透更强 | 跨平台访问、外网访问 |
| DLNA | 局域网内多媒体**只读播放**共享 | 电视、音响等影音设备播放 |

## 二、Samba 配置

1. 路由器 web 页面 → Network Storage，开启 Samba
2. User Management 添加用户
3. 选择要分享的文件夹，设置参数
4. 完成后获得 SMB 链接，通过链接访问

### 手机访问

- 苹果：自带浏览器
- 安卓：ES 文件浏览器 → 新建 → 选择 Samba 协议 → 输入链接 → 账号密码 → 进入文件夹

### 电脑访问（Windows）

1. 控制面板 → 用户账户 → 凭证管理 → Windows 凭证 → 添加凭证（IP、用户名、密码）
2. 文件资源管理器地址栏输入 SMB 链接
3. 输入密码即可访问

## 三、WAN 侧访问安全

**Allow Access Samba from WAN**：
- 控制 Samba 是否对 WAN 侧开放，**默认关闭**（仅内网可访问，更安全）
- 开启后公网环境安全风险极高，且运营商通常**封禁 445 端口**导致无法连通
- 结论：非必要不开启；外网访问优先走 VPN 隧道接入内网再访问

## 四、WebDAV 启用

- 功能选项相比 Samba 多：HTTP/HTTPS 协议切换、自定义服务端口
- 无独立共享名（源于底层协议差异）
- 跨平台兼容性更好、外网穿透能力更强

## 五、DLNA 定位

- 侧重局域网内**影音内容的互通播放**（只读）
- 与 Samba 的区别：Samba 是通用型全文件共享，支持读写管理与权限控制，更适合电脑文件操作
