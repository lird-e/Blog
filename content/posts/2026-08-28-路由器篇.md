## 一、四种工作模式

路由器主要有 4 种工作模式：**路由模式**、**中继模式**、**热点共享**、**USB Modem 模块**。

这 4 种模式出问题时各有各的坑，常见问题如下：

| 模式           | 主要问题                                                          |
| -------------- | ----------------------------------------------------------------- |
| 路由模式       | 路由器限速，跑不到原有带宽                                        |
| 中继模式       | 主要是网络认证方面的问题                                          |
| 热点共享       | 目前暂无大问题，排查时注意手机需开启 USB 网络共享                 |
| USB Modem 模块 | 主要针对随身 WiFi，坑较大——很多随身 WiFi 设备不支持（不确定是 USB 口供电不足还是兼容性问题） |

## 二、经典问题处理

### 1. 随身 WiFi 支持

我们设备对随身 WiFi 的支持相对较差。遇到此类问题，输入命令 `/网卡`，并按以下话术回复：

> **USB 网卡支持情况**：目前测试华为和中兴的型号支持较好，可优先考虑：
>
> - **华为**：E8372h-155、E5576-855、8372h-150a、E3372-607、K5161h、E3372-920
> - **中兴**：MF833U、MF79U、MF932、MF833U1
> - **蒲公英**：贝锐蒲公英 X4U（4G 随身 WiFi）
>
> 市场上的讯优、飞猫等设备大部分也支持，小部分可能不支持（受网卡模块因素影响；目前大部分网卡的系统驱动会识别成热点分享，不影响使用）。

排查步骤如下：

1. **检查 USB 供电是否充足**：部分随身 WiFi 设备本身为 5V/3A，这类设备路由器大概率不支持。以 MT3600BE 为例，其 USB 供电仅 5V/2A，且路由器负载较高时，默认适配器能否稳定供电还不确定。
2. **检查网卡驱动识别**：路由器需能正确识别 USB 网卡的驱动。建议用户购买上文推荐型号，且不保证后续机型都能适配。

### 2. 跑不到原有带宽

该问题比较玄学，很多时候反复调试也达不到应有水平。可按以下顺序排查：

1. 检查是否开启了 **MLO**，关闭 MLO 后观察 5G 网速是否恢复正常；
2. 调整**信道和频宽**（网络不稳定时，一味调高速率反而会导致速率偏低）；
3. 如无 IPv6 使用需求，可**关闭 IPv6** 后再测试。

### 3. 网络时不时断连

该问题成因复杂，涉及多方面因素，例如：上级网络异常、物理硬件故障、协商问题、路由器本身 bug 等。

如果是中继模式，可尝试修改中继的频宽，并降级为 WiFi 6——WiFi 7 的网络驱动还不完善，存在一些 bug。

处理方式：先确认上级网络是否异常，再按《排障引导》中的「排障信息收集」清单收集客户设备信息，反馈给技术支持。

### 4. Good Cloud 云服务问题

Good Cloud 云服务有国内和国外两个平台，两个平台的数据互不互通。有的客户会修改国家码，导致路由器自动连接海外服务器；如果路由器设备无法访问该地址，Good Cloud 功能将无法使用。

此时需通过 SSH 进入命令行，按以下步骤排查修复：

1. **查看配置文件**，确认服务器地址是否为国内地址：

   ```bash
   cat /etc/config/gl-cloud
   ```

2. **修改配置文件**，将地址改回国内地址：

   ```bash
   vi /etc/config/gl-cloud
   ```

   在 vi 中按 `i` 进入编辑模式，将 server 字段改为国内地址后，按 `Esc` 退出编辑，输入 `:wq` 保存并退出。

3. **提交修改并重启服务**：

   ```bash
   uci set gl-cloud.@cloud[0].server
   uci commit gl-cloud
   /etc/init.d/gl-cloud restart
   ```

等待几秒后再次尝试，即可正常使用。


### 5. 蜂窝上网

蜂窝网络问题也比较玄学，常见问题有蜂窝无法拨号上网、蜂窝频繁断连。这类问题可以到《Cellular 排障》文档中查询；国内目前只有 XE300，可重点搜索 XE300 相关内容。

如果只是断连，可尝试切换上网协议，观察是否改善；若仍无改善，则执行排障指令收集设备信息，反馈给技术支持。
