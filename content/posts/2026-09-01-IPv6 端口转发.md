> **用途**：为内网设备配置 IPv6 端口转发，实现从外部通过 IPv6 访问内网服务。
>
> **适用设备**：GL.iNet 路由器（LuCI/OpenWrt，以下截图基于 GL-MT6000）

## 设置步骤

### 1. 进入 LuCI 界面

进入路由器 **高级设置 → LuCI**，打开 LuCI 管理页面。

![进入 LuCI](/Blog/assets/images/IPv6端口转发/01-进入LuCI.png)

### 2. 进入防火墙页面

点击 **网络 → 防火墙**。

![网络-防火墙](/Blog/assets/images/IPv6端口转发/02-网络防火墙.png)

### 3. 打开通信规则

在防火墙页面点击 **通信规则** 标签页。

![防火墙-通信规则](/Blog/assets/images/IPv6端口转发/03-防火墙通信规则.png)

### 4. 新增规则

点击 **新增**，创建一条新的通信规则。

![通信规则列表-新增](/Blog/assets/images/IPv6端口转发/04-通信规则列表新增.png)

### 5. 常规设置

在 **常规设置** 页按如下填写：

| 配置项   | 填写内容                                       |
| -------- | ---------------------------------------------- |
| 名称     | 自己取一个名字                                 |
| 协议     | TCP（如需 UDP 再勾选 UDP）                     |
| 源区域   | wan（选 WAN 口）                               |
| 源地址   | 保持不变，不添加 IP                            |
| 源端口   | 任意                                           |
| 目标区域 | lan（保持 LAN 口）                             |
| 目标地址 | 添加目标 IP（填写内网设备的 IPv6 地址）        |
| 目标端口 | 填写需要转发的端口                             |
| 操作     | 接受                                           |

![常规设置](/Blog/assets/images/IPv6端口转发/05-常规设置.png)

### 6. 高级设置：限制为仅 IPv6

切换到 **高级设置** 标签页，将 **限制地址类型** 由「IPv4 和 IPv6」修改为 **仅 IPv6**。

![高级设置-仅IPv6](/Blog/assets/images/IPv6端口转发/06-高级设置仅IPv6.png)

### 7. 保存并应用

确认规则已出现在列表中后，点击 **保存并应用** 使其生效。

![保存并应用](/Blog/assets/images/IPv6端口转发/07-保存并应用.png)
